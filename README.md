# Personal-Finance-Dashboard

A desktop personal-finance tracker built with CustomTkinter and an MVC architecture.

To run the code, follow these steps

1. git clone https://github.com/basangouda46/Personal-Finance-Dashboard.git

2. Prerequisites
  - Install Python and run `pip install -r requirements.txt`.
  - Launch the application with `python3 main.py`.

3. (macOS) To package the application, run `python3 setup.py py2app -d ../`.
